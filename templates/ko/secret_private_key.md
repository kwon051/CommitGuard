# 개인 키 파일 노출

**무엇이 발견됐나요?**
저장소에 개인 키(-----BEGIN ... PRIVATE KEY-----로 시작하는 파일)가 올라가 있습니다.

**왜 위험한가요?**
개인 키를 가진 사람은 이 키로 서버에 접속하거나, 내가 서명한 것처럼 흉내 낼 수 있습니다. 개인 키는 절대 저장소에 두면 안 됩니다.

**어떻게 고치나요?**
1. 이 키를 등록한 서버·서비스에서 공개 키 등록을 해제합니다.
2. 새 키 쌍을 만들어 저장소 밖(내 컴퓨터의 ~/.ssh 등)에 보관합니다.
3. 키 파일 이름이나 확장자(*.pem, id_rsa)를 `.gitignore`에 추가합니다.
4. 코드에서 지워도 Git 기록에는 남아 있으므로, 1번(등록 해제)을 반드시 먼저 합니다.

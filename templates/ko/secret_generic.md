# 비밀번호·API 키 값 노출

**무엇이 발견됐나요?**
코드나 설정 파일에 비밀번호 또는 API 키로 보이는 값이 그대로 적혀 있습니다.

**왜 위험한가요?**
저장소를 볼 수 있는 사람은 누구나 이 값으로 DB나 외부 서비스에 접속할 수 있습니다.

**어떻게 고치나요?**
1. 해당 비밀번호나 키를 새 값으로 바꿉니다.
2. 새 값은 코드 대신 `.env` 파일에 저장하고, 코드에서는 `os.environ`으로 읽습니다.
3. `.env`를 `.gitignore`에 추가합니다.
4. 코드에서 지워도 Git 기록에는 남아 있으므로, 1번(값 변경)을 반드시 먼저 합니다.

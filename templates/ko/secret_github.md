# GitHub 개인 접근 토큰 노출

**무엇이 발견됐나요?**
코드에 GitHub 개인 접근 토큰(ghp_로 시작하는 값)이 그대로 적혀 있습니다.

**왜 위험한가요?**
이 토큰을 가진 사람은 내 GitHub 계정처럼 저장소를 읽고, 코드를 바꾸고, 지울 수 있습니다. 비공개 저장소의 코드까지 새어 나갈 수 있습니다.

**어떻게 고치나요?**
1. GitHub → Settings → Developer settings → Personal access tokens에서 이 토큰을 삭제합니다.
2. 꼭 필요한 권한만 가진 새 토큰을 발급받아 `.env` 파일에 저장합니다.
3. `.env`를 `.gitignore`에 추가합니다.
4. 코드에서 지워도 Git 기록에는 남아 있으므로, 1번(토큰 삭제)을 반드시 먼저 합니다.

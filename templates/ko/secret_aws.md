# AWS 접근 키 노출

**무엇이 발견됐나요?**
코드에 AWS 접근 키(AKIA로 시작하는 값)가 그대로 적혀 있습니다.

**왜 위험한가요?**
저장소를 볼 수 있는 사람은 누구나 이 키로 AWS 계정에 접속해 서버를 만들거나 데이터를 볼 수 있습니다. 공개 저장소에 올라간 키는 자동 수집 프로그램에 금방 발견되어 큰 요금이 청구될 수 있습니다.

**어떻게 고치나요?**
1. AWS 콘솔 → IAM → 사용자 → 보안 자격 증명에서 이 키를 비활성화하고 삭제합니다.
2. 새 키를 발급받아 코드가 아닌 `.env` 파일에 저장합니다.
3. `.env`를 `.gitignore`에 추가해 저장소에 올라가지 않게 합니다.
4. 코드에서 지워도 Git 기록에는 남아 있으므로, 1번(키 폐기)을 반드시 먼저 합니다.
